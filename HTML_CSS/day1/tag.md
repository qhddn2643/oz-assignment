# HTML 태그 정리 — 1일차

## 1. HTML 태그란?

HTML 태그는 웹페이지에서 **내용의 의미와 구조를 나타내는 표시**이다. 대부분의 태그는 여는 태그와 닫는 태그를 함께 사용한다.

```html
<p>안녕하세요.</p>
```

- `<p>`: 여는 태그
- `Hello, HTML`: 태그 안의 내용
- `</p>`: 닫는 태그

태그 안에 다른 태그를 넣는 것을 **중첩(nesting)**이라고 한다.

```html
<body>
  <h1>One</h1>
  <p>Hello, HTML</p>
</body>
```

`<hr>`, `<img>`, `<input>`처럼 **닫는 태그를 사용하지 않는 태그(빈 요소)**도 있다.

## 2. HTML 문서의 기본 구조 태그

| 태그 | 역할 | 기억하기 |
|---|---|---|
| `<html>` | HTML 문서 전체를 감싸는 최상위 요소 | 문서의 바깥 틀 |
| `<head>` | 문서 제목이나 설정 정보를 담는 영역 | 화면보다 문서 정보에 관한 영역 |
| `<title>` | 브라우저 탭에 표시할 제목을 지정 | 탭 제목 |
| `<body>` | 웹페이지에 표시되는 본문 내용을 담음 | 실제 페이지 내용 |

```html
<!DOCTYPE html>
<html lang="ko">
<head>
  <meta charset="UTF-8">
  <title>나의 첫 페이지</title>
</head>
<body>
  <h1>반갑습니다!</h1>
  <p>HTML 실습 1일차</p>
</body>
</html>
```

**코드 읽기**

- `<html>` 안에 `<head>`와 `<body>`가 들어간다.
- `<head>` 안의 `<title>`은 브라우저 탭 제목을 설정한다.
- `<body>` 안의 `<h1>`, `<p>`가 페이지 본문에 표시된다.
- `<!DOCTYPE html>`은 HTML 문서 유형을 알리는 **선언**이며 태그는 아니다.
- `<meta>`는 인코딩 등의 메타데이터를 설정하는 태그이다. 교안에서는 `<head>`의 역할로 소개되며, 위 코드는 실습용으로 보충한 예시이다.

## 3. 텍스트를 표현하는 태그

### 3.1 `<p>` — 문단

글을 **하나의 문단**으로 묶는다. 문단을 나누면 브라우저가 보통 문단 사이에 기본 여백을 둔다.

```html
<p>첫 번째 문단</p>
<p>두 번째 문단</p>
```

`<p>` 없이 소스 코드에서 줄만 바꾸었다고 해서 화면에서도 별도 문단이 만들어지는 것은 아니다.

### 3.2 `<h1>` ~ `<h6>` — 제목

제목의 **단계와 중요도**를 나타낸다. `<h1>`이 가장 상위 제목이고 `<h6>`이 가장 하위 제목이다.

```html
<h1>웹 개발 학습</h1>
<h2>HTML</h2>
<h3>HTML 태그</h3>
<p>제목 아래에 내용을 작성</p>
```

제목 태그는 단순히 글자 크기를 키우기보다 **문서의 제목 구조를 만드는 목적**으로 사용한다.

### 3.3 `<hr>` — 내용의 구분

주제가 달라지는 지점 등에서 **내용의 의미상 구분**을 나타낸다. 브라우저에서는 보통 가로선으로 보인다.

```html
<h2>소개</h2>
<p>나에 대한 내용</p>
<hr>
<h2>취미</h2>
<p>좋아하는 활동을 소개</p>
```

`<hr>`은 닫는 태그가 없다.

## 4. 목록을 만드는 태그

| 태그 | 의미 | 표시 방식 |
|---|---|---|
| `<ul>` | 순서가 없는 목록 | 보통 ● 같은 글머리 기호 |
| `<ol>` | 순서가 있는 목록 | 보통 1, 2, 3 번호 |
| `<li>` | 목록 안의 개별 항목 | `<ul>` 또는 `<ol>` 안에서 사용 |

**순서가 없는 목록**

```html
<ul>
  <li>HTML</li>
  <li>CSS</li>
  <li>JavaScript</li>
</ul>
```

예상 표시: HTML, CSS, JavaScript 앞에 글머리 기호가 붙는다.

**순서가 있는 목록**

```html
<ol>
  <li>파일 생성</li>
  <li>코드 작성</li>
  <li>브라우저 확인</li>
</ol>
```

예상 표시: 각 항목 앞에 1, 2, 3이 붙는다.

**핵심:** `<ul>`과 `<ol>`은 목록의 종류를 결정하고, `<li>`는 각 항목을 표현한다.

## 5. 표를 만드는 태그

| 태그 | 역할 |
|---|---|
| `<table>` | 표 전체 |
| `<thead>` | 표의 머리글 구역 |
| `<tbody>` | 표의 데이터 구역 |
| `<tr>` | 표의 한 행(row) |
| `<th>` | 행이나 열의 제목을 나타내는 셀 |
| `<td>` | 일반 데이터 셀 |

```html
<table>
  <thead>
    <tr>
      <th>이름</th>
      <th>나이</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>Alex</td>
      <td>20</td>
    </tr>
    <tr>
      <td>Bob</td>
      <td>30</td>
    </tr>
  </tbody>
</table>
```

위 코드는 다음과 같은 표를 만든다.

| 이름 | 나이 |
|---|---:|
| Alex | 20 |
| Bob | 30 |

- `<tr>` 하나가 **가로 한 줄**이다.
- `<th>`는 보통 제목 셀, `<td>`는 데이터 셀로 사용한다.

## 6. 이미지와 링크 태그

### 6.1 `<img>` — 이미지 삽입

웹페이지에 이미지를 표시한다.

```html
<img src="pizza.jpeg" alt="접시에 담긴 피자">
```

| 속성 | 의미 | 예시 |
|---|---|---|
| `src` | 이미지 파일 경로 또는 URL | `src="pizza.jpeg"` |
| `alt` | 이미지를 대신 설명하는 텍스트 | `alt="접시에 담긴 피자"` |

- `src`에 적은 파일이 실제 경로에 있어야 이미지가 표시된다.
- `alt`는 이미지가 보이지 않거나 화면 읽기 도구를 사용할 때 중요하다.
- `<img>`는 닫는 태그가 없다.

### 6.2 `<a>` — 하이퍼링크

텍스트 등을 클릭했을 때 다른 페이지나 주소로 이동할 수 있게 한다.

```html
<a href="https://www.google.com">Google 바로가기</a>
```

- `href`: 이동할 대상 주소이다.
- 태그 사이의 `Google 바로가기`: 화면에 보이는 링크 텍스트이다.

## 7. `<form>`, `<input>`, `<button>` — 입력과 전송

### 7.1 `<form>` — 입력 데이터를 묶어 전송

사용자가 입력한 내용을 **하나의 양식으로 묶어 전송**하는 태그이다.

```html
<form action="https://www.google.com/search">
  <input type="search" name="q" placeholder="검색어 입력">
  <button type="submit">검색</button>
</form>
```

| 속성 | 의미 | 예시 |
|---|---|---|
| `action` | 입력 데이터를 보낼 주소 | `action="https://www.google.com/search"` |

### 7.2 `<input>` — 입력 칸

사용자가 값을 입력하거나 선택하는 칸을 만든다.

```html
<input
  type="search"
  name="q"
  placeholder="Search..."
>
```

| 속성 | 역할 | 예시 |
|---|---|---|
| `type` | 입력 방식 지정 | `search`, `text` |
| `name` | 전송할 데이터의 이름(키) | `name="q"` |
| `placeholder` | 비어 있을 때 보여줄 안내 문구 | `placeholder="Search..."` |

**중요:** `name="q"`가 있다면 검색어가 `q=검색어` 형태로 전달될 수 있다. `placeholder`는 안내 문구일 뿐 전송되는 값이 아니다.

`<input>`은 닫는 태그가 없다.

### 7.3 `<button>` — 버튼

사용자가 누를 수 있는 버튼을 만든다. 폼 안에서 데이터를 제출할 때 사용한다.

```html
<button type="submit">전송</button>
```

- `type="submit"`: 폼을 제출하는 버튼이다.
- `type="button"`: 기본적으로 폼을 제출하지 않는 일반 버튼이다.
- `<form>` 안에서 `type`을 생략한 `<button>`은 기본적으로 제출 버튼으로 동작한다.

**한 줄 정리:** 태그는 웹페이지의 **구조와 의미**를 만들고, 속성은 태그의 **세부 동작과 정보**를 지정한다.
